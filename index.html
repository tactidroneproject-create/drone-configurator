Guía de Conexión Básica

Basado en nuestro Prototipo Nº1 [1]:

  • Motores Brushless: Tienen 3 cables sin polaridad fija; el sentido de giro se cambia intercambiando dos cables o mediante software [2, 3].
  • Stack de Vuelo: Conexión ESC ↔ FC mediante cable JST-SH de 8-10 pines que transmite señales, telemetría y energía [4].
  • GPS BN-880: Requiere conexión UART para el GPS y bus I²C para la brújula [5].

Configuración de Firmware

Betaflight: Ideal para FPV; solo requiere habilitar GPS en el puerto UART correspondiente [6].

INAV: Recomendado para Long Range; soporta brújula y modos de navegación avanzados [6].

ArduPilot: Para misiones tácticas; requiere firmware 4.1+ para protocolos como CRSF/ELRS [7].
