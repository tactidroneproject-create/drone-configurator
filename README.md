# Drone Configurator

## Overview
Drone Configurator is an early-stage prototype of a web-based tool aimed at helping users design, understand, and validate drone configurations using reliable and tested components.

The goal of this project is not to sell drones directly, but to provide **clear, curated, and technically sound information** that reduces risk, saves time, and avoids incompatible builds.

This repository currently hosts a **front-end prototype** intended to evolve into a configuration and validation platform for DIY, semi‑professional, and small‑scale commercial drone projects.

---

## Project Motivation
Building drones today involves:
- fragmented information
- inconsistent recommendations
- low-quality or incompatible components
- high learning costs for new builders

Many users end up wasting time and money before achieving a stable and functional build.

This project aims to centralize **validated configurations**, trusted suppliers, and technical rationale in a single, easy-to-use interface.

---

## Current Scope (MVP)
- Static web prototype (no backend)
- Drone configuration flow inspired by automotive configurators
- Component selection (frame, motors, ESC, FC, battery, payload)
- Compatibility logic and technical notes
- External links to recommended suppliers

The prototype is intentionally simple and focused on demonstrating the concept.

---

## What This Is

## What This Is NOT
